# 차원대충돌!

학교 창작 보드게임을 위한 최대 6인 온라인 테이블입니다. Node.js 서버가 방, 카드, 커서를 관리하며 SSE와 HTTP 요청으로 모든 참가자에게 상태를 동기화합니다. 외부 패키지 설치가 필요 없습니다.

## 실행

Node.js 22.8 이상을 설치한 뒤 프로젝트 폴더에서 실행하세요.

```sh
npm start
```

브라우저에서 http://localhost:3000 에 접속하세요. 같은 네트워크의 다른 기기에서는 서버 컴퓨터의 IP 주소와 3000 포트로 접속합니다. 서버 방화벽에서 해당 포트 접속이 허용되어야 합니다. 인터넷 친구들과 사용하려면 Node.js를 실행하는 호스팅에 배포하고 HTTPS 주소를 공유하세요. `PORT` 환경변수로 포트를 바꿀 수 있습니다.

## 사용법

1. 닉네임을 설정하고 새 테이블을 만들거나 열린 테이블에 참여합니다.
2. 입장 즉시 중앙에 120장의 카드가 뒷면으로 가지런히 쌓여 있습니다. 위치와 각도는 동일하고 순서만 섞입니다.
3. 카드를 클릭한 채 드래그해 이동합니다. 잡고 있는 동안 휠을 돌리면 15도 단위로 회전합니다.
4. 개인 영역은 위 2곳, 아래 2곳, 좌우 1곳씩 배정됩니다. 자신의 영역에 있는 앞면은 자신에게만 보입니다.
5. 개인 영역에서 공용 공간으로 나오는 카드는 뒷면이 됩니다. 공용 공간에서 더블클릭하면 공개/비공개를 전환합니다.
6. Ctrl+D로 개발자 콘솔을 열고 `user257`을 실행합니다. 앞면 이미지를 순서대로 최대 120장 등록할 수 있습니다. 미등록 앞면은 흰색입니다. 뒷면도 같은 콘솔에서 교체할 수 있습니다.
7. 오른쪽 위 나가기를 누르면 로비로 돌아갑니다.

## 서버 동작 및 보관

- 카드 앞면 이미지 요청은 서버에서 현재 공개 여부를 확인합니다.
- 커서 색상과 개인 영역은 방 안에서 중복되지 않습니다.
- 동시에 한 카드에 접근하면 먼저 잡은 사람에게 잠시 이동 권한을 줍니다.
- 연결이 끊긴 사용자는 마지막 요청 이후 약 20~25초에 퇴장 처리됩니다.
- 카드 리소스는 서버의 `data/resources.json`에 저장되며 모든 방에서 공통으로 사용합니다. 이미지 한 장은 PNG/JPG/WebP 2MB 이하입니다.
- 방과 카드 배치는 서버 메모리에 있으며 재시작하면 초기화됩니다. 빈 방은 정리됩니다. 호스팅은 단일 Node.js 프로세스와 쓰기 가능한 영구 디스크를 사용하세요. SSE 버퍼링을 끄고 스트리밍 응답을 허용해야 합니다.
- `user257`은 요청한 리소스 편집용 공통 코드입니다. 운영자별 계정 인증은 포함하지 않습니다.

## 검증

```sh
npm test
```

초기 정렬과 셔플, 6인 제한, 중복 없는 색상/좌석, 카드 잠금, 회전, 개인 영역 앞면 제한, 영역 이탈 시 뒤집기, 공개 뒤집기, 개발자 인증, 퇴장 후 재참여를 서버 핸들러에 직접 요청해 검사합니다.

이 작업 환경에서는 서버 포트 열기가 제한되어 브라우저와 실제 여러 기기 접속 검증은 진행하지 못했습니다. 공개 배포 주소도 아직 없습니다.

## Render 무료 서버에 배포

1. 이 프로젝트 폴더의 파일을 GitHub 저장소 루트에 올립니다. `server.mjs`, `package.json`, `render.yaml`이 저장소 최상단에 있어야 합니다. `data/`는 올리지 않습니다.
2. 카드 원본을 `cards/`에 넣습니다. `001.png`부터 번호순으로 최대 120장, 뒷면은 `back.png`입니다. 아직 이미지가 없으면 비워 두어도 됩니다.
3. Render에 로그인하고 **New → Blueprint**에서 해당 저장소를 연결합니다.
4. 설정 화면에서 **Free** 플랜인지 확인하고 배포합니다. `render.yaml`에 빌드 `npm run build`, 시작 `npm start`, 상태 확인 `/healthz`가 설정되어 있습니다. 유료 디스크나 데이터베이스는 생성하지 않습니다.
5. 배포 성공 후 Render가 표시한 웹주소를 친구들에게 공유합니다. 컴퓨터를 계속 켜 둘 필요가 없습니다.

수동 Web Service 생성도 가능합니다. Runtime은 Node, Instance Type은 Free, Build Command는 `npm run build`, Start Command는 `npm start`로 설정하세요.

Render 무료 서버는 15분 미사용 시 절전되고 재기동에 약 1분이 걸릴 수 있습니다. 절전/재시작/재배포 시 진행 중인 방과 콘솔 업로드 변경은 초기화됩니다. `cards/`에 넣어 배포한 원본 이미지는 다음 빌드와 기동에서도 유지됩니다. 트래픽·빌드 무료 한도를 초과할 때의 중단 또는 과금은 Render 계정의 결제 설정을 따릅니다.

- 채팅에 표시된 뒷면 원본 파일은 직접 내려받을 수 없어 포함하지 않았습니다. 현재 뒷면은 보라색/민트 궤도 기본 무늬입니다. 원본을 `cards/back.png` 또는 `back.jpg`로 넣고 다시 시작하면 적용됩니다.
- Windows는 Node.js 설치 후 `실행하기.cmd`를 더블클릭하면 됩니다. npm 명령 입력 없이 카드 목록을 만들고 서버를 실행합니다.
- `npm start`도 시작 전에 카드 목록을 자동 갱신합니다.
- 기본 이미지 목록은 파일 경로만 저장하며, 앞면을 볼 권한이 있을 때 서버가 이미지를 읽습니다. 카드 120장을 한꺼번에 base64로 메모리에 적재하지 않습니다.
- `data/resources.json`에 이전 업로드가 있다면 그 설정이 우선합니다. 기본 120장을 사용하려면 서버 종료 후 그 파일을 백업 이름으로 바꾸고 시작하세요.
- 이 작업 환경의 포트 제한 때문에 실제 브라우저 확인은 진행하지 못했습니다. 빌드, 이미지 무결성 및 서버 직접 요청 테스트를 실행했습니다.

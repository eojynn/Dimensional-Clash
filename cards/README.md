# 기본 카드 이미지

앞면을 이 폴더에 `001.png`, `002.png`처럼 번호순으로 넣어주세요.
PNG/JPG/WebP를 지원하며, 최대 120장, 한 장당 2MB입니다.
공통 뒷면은 `back.png` (또는 back.jpg, back.webp)로 넣어주세요.

`npm run build`는 파일 이름의 숫자 순서대로 카드를 묶어 `resources.json`을 생성합니다.
Render에서도 빌드 때 자동 생성하므로 서버가 절전/재시작되어도 프로젝트에 포함된 원본 카드가 복원됩니다.
이미지가 없는 슬롯은 흰색 앞면, 뒷면이 없으면 기본 무늬를 사용합니다.
카드 파일과 생성된 resources.json을 public 폴더에 넣지 마세요. 서버가 공개 여부를 검사한 뒤 이미지를 전달합니다.

게임 안 콘솔로 업로드한 변경은 Render 무료 서버가 절전/재시작/재배포될 때 없어집니다.
그 변경을 영구 보관하려면 원본 이미지를 이 폴더에 넣고 다시 배포해야 합니다.
